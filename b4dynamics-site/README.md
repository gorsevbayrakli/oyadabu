# b4dynamics — Storytelling web sitesi

Tek dosyalık (`index.html`) statik site. Sunucu ya da build adımı gerekmez; tarayıcıda açmanız yeterli.

## Hikâye akışı
1. **Açılış** — "Her büyük dönüşüm, tek bir sabahla başlar."
2. **Bölüm 1 · Sorun** — Temsili karakter Elif'in kaotik pazartesi sabahı
3. **Bölüm 2 · Rehber** — b4dynamics: 2008, 50+ uzman, Hüfingen / İstanbul / Denver
4. **Bölüm 3 · Plan** — Anla → Tasarla → Uygula & doğrula → Büyüt
5. **Bölüm 4 · Dönüşüm** — Önce/Sonra karşılaştırması, proses ve kesikli üretim
6. **Bölüm 5 · Güçlü bir ağ** — collana IT Group ("collana" = kolye) boncuk motifi
7. **Epilog** — "Hikâyeniz şu an hangi bölümde?" iletişim formu

## Özelleştirme
- **Renkler:** `index.html` içindeki `:root` bloğundaki değişkenler (`--ink`, `--primary`, `--accent` …). Resmi b4dynamics hex kodlarıyla sadece bu blok güncellenmeli.
- **Form:** Şu an yalnızca teşekkür mesajı gösteriyor; gerçek gönderim için `#contactForm` bir arka uca / form servisine bağlanmalı.
- **Görseller:** Tüm görseller SVG/CSS ile üretildi; gerçek fotoğraflar eklenebilir.
